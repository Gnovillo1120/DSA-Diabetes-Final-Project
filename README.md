Hello! This is the final draft of our Diabetes Risk Prediction Model, front-end to backend. The instructions for running this project on our own machine are as follows:
1. Download the zip of files and run on an IDE that will take Python 3.11 code (If there is a file that ends in .pkl, delete them!)
3. Run main.py! This will take some time, all of the hard work is here! (~5-7 minutes)
4. Run train_models.py. This is needed for the risk calculator (~2 minutes)
5. Run other_models.py. This is needed for the model comparison (~30s)
6. Go to your terminal and type "streamlit run app.py"
7. The app should appear in your browser! If your laptop is in dark mode, you can either switch it to light mode, or see the top right three vertical dots, select settings, and pick light mode! This is so you can see all features!
